# GD Skin Studio

[English](README.en.md) | 日本語

Grim Dawn 用の「AI で作った 3D モデルをイリュージョン装備にする MOD」を作る Windows のツールです。
画像（またはテキスト）から 3D モデルを生成し、Grim Dawn の男性・女性キャラクター用に変換して、
頭装備のイリュージョンとして使える MOD を作り、ゲームのフォルダーに導入します。

- 入力した画像や文章は、この PC の外には送信しません（3D 生成も手元の GPU で行います）。
  インターネットに接続するのは、セットアップで 3D 生成の実行環境とモデルを取得するとき（初回の取得と、設定画面の
  「TRELLIS 実行環境の管理」での照合し直し・入れ直し）だけです。3D 生成の途中では、足りないファイルがあっても取得せずに
  エラーで止まります（既定の動き）。生成の詳細設定の「通信の遮断」をオンにすると、生成の処理（Python）からの外部への接続を拒否します（ネイティブのコードが自分で開く接続は対象外）。
- このツールは非公式のファン製ツールです。Crate Entertainment（Grim Dawn の開発元）、Microsoft（TRELLIS の開発元）ほか、
  このツールが使うソフトウェアやモデルの開発元とは関係がありません（[免責事項](#免責事項)）。

> 現在の版は **1.0.0**（初版）です。動作を確かめた環境は限られています（[動作環境](#動作環境)）。
> 不具合や「この環境で動いた・動かなかった」の報告を歓迎します（[CONTRIBUTING.md](CONTRIBUTING.md)）。
>
> この README は、リポジトリの今のソースに合わせてあります。[CHANGELOG.md](CHANGELOG.md) の「未公開」にある変更は、
> Releases で公開している配布用 ZIP には、まだ入っていません。

## できること

- **画像から 3D モデルを生成**: 全身が写った 1 体のキャラクターの画像から、Microsoft の [TRELLIS](https://github.com/microsoft/TRELLIS)
  （TRELLIS-image-large）で 3D モデルを作ります。背面・側面の画像を足すこともできます（最大 4 枚）。
  背景のある画像は自動で背景を除きます。被写体が端で切れている・小さい・複数の物体がある画像には注意を出します（生成は止めません）。
- **テキストから 3D モデルを生成**（任意）: 英語の文章から TRELLIS-text-xlarge で作ります（追加の取得と、CLIP の注意事項への同意が必要）。
  文章のひな形と、生成 AI が読む長さ（トークン数）の目安を表示します。
- **Grim Dawn 用に変換**: 生成したモデル（または他のツールで作った GLB ファイル）を、ゲームの男性用・女性用の全身スキンメッシュ（`.msh`）と
  テクスチャ（`.tex`）に変換します。姿勢・体格の合わせ込み、頂点数の調整、ボーンの割り当てを自動で行います。
- **3D プレビュー**: 生成結果と男性用・女性用の変換結果を、回して確認できます。正面が後ろを向いていたら 180° 回して変換し直せます。
  自動で選ばれた候補と違う候補（シード）を選んで作り直すこともできます。
- **MOD の作成と導入**: 作った装備に名前（英語・日本語）を付けて装備一覧に保存し、全装備をまとめた MOD を作って
  Grim Dawn に導入します。導入の前に元のファイルを退避し、アンインストールで元に戻せます。
  MOD には、ゲームの 13 言語の表示名のファイル（`Text_XX.arc`）が入ります（日本語の設定のゲームでは日本語名・日本語の説明が出ることをゲーム内で確かめました。英語と日本語以外の設定で読まれるかは未確認）。
- **ゲームでの入手**: 作った装備は、Devil's Crossing の補給官（Survivors の評判が Friendly 以上）から
  イリュージョンとして入手し、頭装備のイリュージョンとして使います。胴・脚・手・足・肩を見えなくする（透明の）イリュージョンも付きます。
  メダルの見えないイリュージョンも加わります（胸のバッジが消える見込み。ゲーム内では未確認）。
- **受け渡し**: 作った装備を他の利用者と受け渡すファイル（`.gdskin`）と、マルチプレイ用に MOD をそのまま渡す共有ファイル（`.gdskinmod`）を作れます。
- **英語の画面**（任意）: 表示言語の既定は日本語です。設定画面の「表示言語（Language）」で English を選ぶと、バックエンドからのメッセージや
  エラーの詳細も含めて、アプリの表示が英語になります（[詳細設定と追加の機能](#詳細設定と追加の機能)）。

## 動作環境

### 必須

- Windows 10 / 11（64 bit）
- Grim Dawn（Steam 版）と拡張「Ashes of Malmouth」（MOD の雛形に Ashes of Malmouth のデータを使います）
- ディスクの空き: アプリ 約 270 MB（ZIP は約 127 MB）、3D 生成の実行環境とモデル 約 13 GB
  （取得中は一時的にもっと要ります。新しく取得する場合は約 18 GB の空きを求め、セットアップの画面に表示します。
  テキスト→3D を加えると、さらに約 6 GB）
- 初回のセットアップのときのインターネット接続（約 8.6 GB を取得します）

### 3D 生成（画像・テキストから作る）に必要なもの

- NVIDIA の GPU（GPU メモリ 12 GB 以上。16 GB 以上を推奨。compute capability 6.0 以上）
- NVIDIA のドライバー R570 以降（CUDA 12.8 に対応したもの）
- Microsoft Visual C++ 再頒布可能パッケージ（x64）の新しい版。Grim Dawn と一緒に古い版が入っていることが多く、
  古い版のままだと、取得の後の動作確認で失敗します。環境の確認で古い・無いと出たら、
  [Microsoft の配布元](https://aka.ms/vc14/vc_redist.x64.exe)から最新版を入れてください（管理者権限が要ります）。

> GPU メモリが 12 GB 以上 16 GB 未満の GPU では、セットアップの取得を始める前に注意を出し、続けるかを選べます。
> TRELLIS の README は 16 GB 以上を必須としており、この大きさの GPU での生成は確かめていません。
> メモリ不足で失敗するときは、生成の詳細設定の「低 VRAM モード」を試してください（24 GB の GPU で、最大の使用量が約 14 GB から約 10 GB に
> 下がることを計測しました。12〜16 GB の GPU での成否は未確認です）。
>
> 動作を確かめたのは GeForce RTX 5090 Laptop GPU（24 GB）・Windows 11（日本語）の 1 台だけです。
> 他の GPU（RTX 40 系以前など）、Windows 10、日本語以外の Windows では確かめていません。
> GPU が無くても、他のツールで作った GLB ファイルの変換・MOD の作成・導入は使えます。
> ただし、頂点が 25,000 を超える GLB や、マテリアル・テクスチャが複数ある GLB を変換するときは、UV を作り直す部品が
> Windows の Visual C++ ランタイムを使うため、上の Visual C++ 再頒布可能パッケージの新しい版が要ります
> （古い版だけの PC でどうなるかは確かめていません）。

### 不要なもの

- .NET のランタイム、Python、Visual Studio、CUDA Toolkit、git は要りません
  （必要なものは同梱しているか、初回のセットアップで取得します）。
  管理者権限も要りません（Visual C++ 再頒布可能パッケージを入れる・入れ直す場合を除く）。
- 3D プレビューには Microsoft Edge WebView2 ランタイムを使います。Windows 11 には標準で入っています。
  無い場合は [WebView2 のページ](https://developer.microsoft.com/microsoft-edge/webview2/)の「Evergreen ブートストラップ」で入れてください。

## 導入（配布用 ZIP から）

1. [Releases](../../releases/latest) から `GDSkinStudio-<版>-win-x64.zip` をダウンロードします。
2. （おすすめ）ZIP が壊れていない・すり替えられていないことを確かめます。Releases のページに書かれている SHA-256 と、手元の ZIP の値を比べます。
   ZIP を置いたフォルダーで PowerShell を開き、次を実行します（表示された 64 文字が一致すれば同じものです）。

   ```powershell
   Get-FileHash .\GDSkinStudio-1.0.0-win-x64.zip -Algorithm SHA256
   ```

   一致しない場合は使わずに、ダウンロードし直してください（展開した後の各ファイルの SHA-256 は `MANIFEST.txt` にあります）。
3. ZIP を好きなフォルダーに展開します（例: `C:\Tools\GDSkinStudio`）。
   - `C:\Program Files` の中は書き込みが制限されるので避けてください。
   - パスに日本語などの全角文字や é などの英語以外の文字を含まない、短いフォルダーを推奨します。
   - ZIP の中のまま実行せず、必ず展開してください。
4. 展開したフォルダーの `GDSkinStudio.exe` を起動します。同じデータフォルダーでは、アプリは 1 つだけ起動できます。

データフォルダー（既定は `%LOCALAPPDATA%\GrimDawnSkinMOD`）のパスにも、同じく全角文字などを含まないことを推奨します。
Windows の利用者名に全角文字があると、既定のデータフォルダーのパスにもその文字が入ります。ゲーム付属のツールがそうしたパスを扱えない問題への
対策は入れてありますが、全角の利用者名の PC では実機で確かめていません。データフォルダーの場所は
`GDSkinStudio.exe --data-dir <フォルダー>` で変えられます（短い、半角の英数字と記号だけのパスを推奨。設定画面の「環境チェック」の「データ・一時フォルダーのパス」で、
長すぎるパスなどを知らせます）。

### 「Windows によって PC が保護されました」と表示されたら

このツールの EXE にはコード署名をしていません（初版の方針）。そのため初回の起動で、Microsoft Defender SmartScreen が
「Windows によって PC が保護されました」と表示することがあります。

1. 画面の文中の「詳細情報」を押します。
2. 「アプリ: GDSkinStudio.exe」「発行元: 不明な発行元」と表示されるので、アプリの名前を確かめます。
3. 下に出る「実行」を押します。

先に、導入の手順 2 で ZIP の SHA-256 を確かめてください。Windows 11 の「スマート アプリ コントロール」がオンの PC では、
署名の無いアプリとしてブロックされ、「実行」のボタンが出ないことがあります。この場合、このツールは使えません。

## 初回セットアップ

初回の起動では「セットアップ」の画面が開きます。画面の順に進めてください（左の「セットアップ」から、いつでもやり直せます）。

1. **環境の確認**: OS・GPU と GPU メモリ・ドライバー・Visual C++ 再頒布可能パッケージ・空き容量・
   Grim Dawn の場所・Ashes of Malmouth の有無・WebView2 を確かめます（データ・一時フォルダーのパスと、ゲーム付属の ArchiveTool.exe・TextureCompiler.exe の有無は、設定画面の「環境チェック」に出ます）。
2. **導入するもの・同意**: 取得するもの（TRELLIS 実行環境、TRELLIS のモデル、DINOv2、背景除去の u2net）の名前・容量・ライセンス名・配布元を確認します。
   「ライセンス全文」で全文を読めます。GPL のもの（plyfile）、非商用のライセンスの部分を含むもの（kaolin）、注意事項のあるもの（CLIP）など、注意が必要なものには印が付きます。
   テキスト→3D（TRELLIS-text-xlarge と CLIP）は任意です。
   取得先は、既定ではデータフォルダーの中（`%LOCALAPPDATA%\GrimDawnSkinMOD\trellis-runtime`）です。ただし、利用者のフォルダー名に全角文字があるなどで
   その場所が使えない場合は、システムドライブの直下の `%SystemDrive%\GDSkinStudio\trellis-runtime`（多くの PC では `C:\GDSkinStudio\trellis-runtime`）
   になります。空きの多い別のドライブも選べます。80 文字以内で、半角の英数字・記号以外の文字（日本語や全角の文字など）を含まないパスにしてください。
   ドライブの直下（`D:\` など）、Windows・Program Files のフォルダー、Grim Dawn のフォルダー、データフォルダーそのもの（とそれを含む利用者のフォルダーなど）は
   取得先にできません（理由が表示され、「取得を開始」を押せません）。既定の取得先か、`D:\trellis-runtime` のような専用のフォルダーを選んでください。
3. **取得**: 同意すると取得を始めます。ファイルはハッシュ（SHA-256）で照合します。通信が切れても自動で再試行し、取り消しても次は続きから取得します
   （回線の速さによって 10 分〜1 時間ほど）。GPU メモリが 12 GB 以上 16 GB 未満の場合と、Visual C++ 再頒布可能パッケージが古い・無い場合は、
   取得を始める前に確認・注意を出します。
4. **基準メッシュ**: 変換に使うゲームの体のメッシュを、あなたの Grim Dawn から取り出します（ゲームのフォルダーは変更しません）。
5. **起動オプション**: Steam の起動オプション `/basemods` の設定方法を案内します（[下記](#steam-の起動オプション-basemods)）。

> **3D 生成を使わない PC（使える GPU が無い PC など）**: TRELLIS 実行環境が無いと、「3. 取得」から「4. 基準メッシュ」「5. 起動オプション」に
> 進めません（このアプリの制限です）。「後で行う」でセットアップを閉じ、基準メッシュは設定画面の「ゲームから準備する」で準備してください。
> 起動オプション `/basemods` の設定方法は[下記](#steam-の起動オプション-basemods)と、MOD の画面の「/basemods の設定方法」で見られます。
> 「GLB ファイル」の変換と、MOD の作成・導入は使えます（GLB によっては、変換に Visual C++ 再頒布可能パッケージの新しい版が要ります。[動作環境](#動作環境)）。

導入済みのものとライセンスは、設定画面の「セットアップ（導入済みの項目とライセンス）」で確認できます。
取得した実行環境の照合し直し・入れ直し・削除は、設定画面の「TRELLIS 実行環境の管理（照合し直す・入れ直す・削除）」でできます
（[トラブルシューティング](#トラブルシューティング)・[アンインストール](#アンインストール)）。

> **CLIP の注意事項への同意**: CLIP の注意文には、モデルカードの「英語以外の言語では学習・評価されていないため、英語での利用に限るべき」
> という点も含めています。注意文が変わったときは、以前に同意していた場合も、テキスト→3D を使う前にもう一度同意を求めます。
> 注意文は画面の表示言語（日本語・英語）で表示します。どちらの言語の注意文に同意しても有効です（同意の記録には、表示した注意文の言語が残ります）。

> **ライセンスの表示が変わったときの同意し直し**: 同意は表示の内容ごとに記録しているため、アプリの更新でライセンスの表示が変わったときは、
> 次に取得や修復をするときに一度だけ、もう一度同意を求めます
> （セットアップの画面の「2. 導入するもの・同意」でライセンスを確認して、もう一度同意してください。取得済みのファイルは照合して再利用します）。
> 同意し直すまで、セットアップの取得と、設定画面の「Python とパッケージを入れ直す」は同意を求めて止まり、「モデルを照合し直す」は合わないファイルを取り直しません。
> 取得済みの実行環境での生成はそのまま使えます。

> **kaolin の非商用の部分**: 取得するパッケージの kaolin 0.18.0 は、ライセンス名は Apache License 2.0 ですが、
> 同梱の `kaolin/non_commercial`（kaolin の中の FlexiCubes の実装）は NVIDIA Source Code License で、非商用（研究または評価の目的）に限って使えます。
> TRELLIS が使うのは kaolin のごく一部ですが、kaolin を読み込むとこの部分も読み込まれます。この部分は、セットアップ・設定の画面
> （「非商用ライセンスのファイルを含む」の印と注意）とライセンスの一覧に表示しています。このライセンスに沿う範囲でだけ使ってください。

## 使い方

アプリの左の「ヘルプ」（どの画面からでも F1 キーで開けます）に、画面ごとの使い方と入力欄の説明、MOD の導入と元に戻す方法、困ったときの対処をまとめています。

1. **生成**: 左の「生成」で、全身が写った 1 体のキャラクターの画像を選びます（PNG・JPEG・WebP・BMP。背景を透明にした PNG が最適。
   「背景除去を確認」で背景を除いた画像を事前に確認できます）。テキストからも作れます（英語。任意の取得物が必要）。
   「生成を開始」を押すと、3D 生成と男性用・女性用への変換を行います（1〜2 分ほど）。
   - 透明な PNG を自分で作るときは、背景を完全に透明、人物を不透明にしてください。半透明の部分（光・髪・影など）は消えるか暗くなります。
     角だけ透明なスクリーンショットのように、ほぼ全体が不透明な画像は背景が除かれません（注意が出ます）。画像の欄の
     「この画像の詳細設定」→「背景除去を強制する」をオンにするか、背景を透明にした PNG で保存し直すか、JPEG で保存し直してください。
   - iPhone の写真などの HEIC は使えません。JPEG・PNG に変換してから選んでください。
   - 被写体が画像の端で切れている・小さい・離れた物体が複数ある場合は、画像の欄に「被写体についての注意」が出ます（生成は止めません）。
   - テキストでは、文章の欄の下の「ひな形」で例文や条件の前置きを入れられます。生成 AI が読むのは、開始・終了の印 2 つを含めて
     77 トークン（英語でおよそ 50〜60 語）までです。トークン数の目安と、長すぎるときに使われない部分を表示します。
     英語以外の文字を含む語や、全角の英数字・記号（（ ）～ なども含む）があると、直すよう注意を出します。色を書かないと白や灰色の体になりやすいので、髪・服・靴などの色も英語で書いてください。
2. **プレビュー**: 生成結果・男性用・女性用を回して確認します。正面が後ろを向いていたら「180° 回して変換し直す」で直せます。
   ポーズや武器が気になるときは「別のシードで再生成」で作り直せます。プレビューの「候補」のタブには、自動の選別で比べた候補
   （腕の角度・色の有無・除外の理由・武器の疑い）が並び、別の候補を選んで「この候補で作る」で作り直せます。変換の途中で止めたときは、
   今の体の行の「この候補で作る」で変換だけをやり直せます。
3. **保存**: 装備名（英語・日本語）を付けて「装備として保存」を押すと、装備一覧に入ります。英語名は半角英数字と記号を推奨します
   （英語の設定のゲームのフォントは ASCII の文字だけを持つため、日本語や é などは表示されない見込みです。保存するときに注意を出します）。
4. **MOD**: 左の「MOD」で「MOD を作成」→「Grim Dawn に導入」を押します。導入の前に、ゲームが起動していないこと、
   他の MOD のファイルとの競合を確かめ、元のファイルは退避します。「アンインストール」で最初の導入の前の状態に戻せます。
   導入・アンインストールなどの途中でアプリを閉じるときは、アプリはその処理を中止せず、終わるのを待ってから閉じます。
5. **ゲーム**: Steam の起動オプションに `/basemods` を設定して Grim Dawn を起動します。
   1. Devil's Crossing の補給官 Ellis（日本語の設定のゲームでは「エリス - 補給主任」）から「Illusion: <装備名>」（日本語の設定のゲームでは「イリュージョン: <装備名>」）を買い、右クリックで使って収集に加えます（店の画面を開いたまま持ち物の品を右クリックすると売り戻しになるので、店を閉じてから使います）。
   2. 頭・胴・肩・手・脚・足に何かを装備します（イリュージョンは装備中の部位にしか適用できません）。
   3. 幻術師（Illusionist）で、頭には作った装備のイリュージョンを、他の部位には見えない（透明の）イリュージョンを適用します。
      メダルを装備している場合は、メダルにも見えないイリュージョンを適用すると胸のバッジが消える見込みです（ゲーム内では未確認）。

そのほか:

- 他のツールで作った GLB ファイルも「GLB ファイル」の入力から変換できます（GPU は不要）。テクスチャの画像や `.bin` を外部のファイルとして参照する GLB は、
  GLB のフォルダーからの相対パスで参照するものだけを読み込みます（絶対パス・別のドライブ・ネットワーク上の場所などで参照する GLB は、そのファイルを読みに行かずに止めます）。
- 装備一覧の「変換し直す」で、保存した装備を 3D 生成をやり直さずに、今の版の変換で作り直せます（その後「MOD を作成」と「Grim Dawn に導入」をもう一度）。
  確認の画面のチェックで、正面を 180° 回して（または回す前の向きに戻して）変換し直すこともできます（チェックは既定で外れています）。
- 装備一覧の「削除した装備…」で、削除した装備を同じ内部ID のまま元に戻せます（その後、MOD を作成して導入します。
  ゲームで入手済みのイリュージョンを同じものとして使い続けられるかは、ゲーム内で未確認です）。
- 装備一覧の「消耗品の文…」で、補給官で買う消耗品の名前・説明文（英語・日本語）を変えられます（空欄なら既定の文。英語の欄は半角英数字と記号を推奨。ゲームは説明文を半角の空白の位置で折り返すので、日本語の説明文は既定の文と同じく文節の区切りに半角の空白を入れる）。
- 装備一覧の「書き出す…」「読み込む…」で、作った装備を他の利用者と受け渡しできます（`.gdskin`。入力画像とプロンプトは既定で含めません）。

### 詳細設定と追加の機能

次の機能は、使うときだけオンにします。**既定ではどれもオフ**です。

| 場所 | 機能 |
|---|---|
| 生成 →「生成設定」→「詳細設定」 | **サンプリング**: 標準（モデルの既定。25 段）／速い（12 段。画像の入力では TRELLIS の公式デモの設定。候補 1 体あたりの時間が約半分。同じシードでも形や細かさが変わる） |
| 同上 | **低 VRAM モード**: メッシュを作る間、使い終わったモデルを GPU のメモリから外す（最大の使用量が約 3.5〜4.5 GB 下がり、候補 1 体あたり約 2 秒長くなる。24 GB の GPU で計測） |
| 同上 | **通信の遮断**: 生成の間、生成の処理（Python）からの外部への接続を拒否し、試みた接続先をログに残す（ネイティブのコードが自分で開く接続は対象外。生成はもともと通信しません。それを確実にするための設定） |
| 同上 | **MOD のテクスチャ**: 変換で作るテクスチャの最大の大きさ 2048（既定）／1024／512（1024・512 で作った装備のゲーム内の見え方は未確認） |
| 同上 | **候補の保存**: 候補ごとの生成結果を下書きに残し、「この候補で作る」とプレビューの下の「GLB を作り直す」を 3D 生成をやり直さずに行えるようにする（下の注意） |
| 同上 | **背景除去**: 生成の前にアプリ側で背景を除き、後処理（マスクを滑らかにする・縁に残る背景の色を除く・アルファマッティング）を選べる。効果は画像によるので「背景除去を確認」で見比べる（効果はまだ評価していません） |
| 同上 | **見た目の作り直し**（試験的）: 装備一覧に「文章で見た目を作り直す…」を出す。保存した装備の形（姿勢）のまま、英語の文章で色・質感・装飾だけを作り直し、新しい装備として保存する（テキスト→3D の任意部品と CLIP の注意事項への同意が必要。確かめたのは見本 1 体・2 文章だけで、文章どおりの色にならないことや細部の形の変化があります） |
| 生成 → 画像の欄の「この画像の詳細設定」 | **背景除去を強制する**: ほぼ全体が不透明な画像（角だけ透明なスクリーンショットなど）でも、透明な部分を白で塗りつぶしてから背景を除く（u2net が必要） |
| 3D プレビュー | **正面の印**: ゲームの中での正面（+Z）に、床の上の矢印と「正面（+Z）」の文字を出す。チェックボックスは、窓の幅によってモデルの選択の行の右の端か、「ワイヤーフレーム」の右に出る（3D のモデルを表示しているときだけ） |
| 設定 →「表示言語（Language）」 | **English**: 英語の画面（既定は日本語）。English を選んで「設定を保存」を押し、アプリを起動し直すと反映されます（バックエンドもアプリと一緒に起動し直します）。バックエンドや生成・変換の処理からのメッセージ、エラーの「詳細」、環境の確認、セットアップの項目とライセンスの説明、mods フォルダーの表、新しく書かれるログの行を含めて、アプリの表示はすべて英語になり、CLIP の注意文も英語で表示します。日本語のまま残るのは、切り替える前に書かれたログの行（書いたときの言語のまま）と、利用者が入力した文（装備名など）です。エラーの「詳細」に入る Windows のエラーの文（「指定されたファイルが見つかりません」など）は、Windows の表示言語のままです。開発者向けの道具（コマンドラインの gdconvert・modbuilder、配布物の作成と公開の検査のスクリプト）と、docs/ の文書（マルチプレイの確認手順）は日本語だけです。英訳はゲームの公式の英語の用語に合わせましたが、英語を母語とする人による確認はしていません。バックエンドに接続できないときも、表示言語と Python の場所は保存できます |

- **候補の保存の容量**: 1 体あたり約 45 MB（候補 4 体で約 180 MB。候補の選別が 2 回目まで進むとその 2 倍）を使います。装備や共有ファイルには入りません。
  生成結果は下書きを保存・破棄するまで残り、そのときに消えます。ただし、設定の「保存した後も生成途中のファイル（下書き）を残す」がオンのときと、
  変換に失敗した下書きでは残ります（失敗した下書きは、設定の「データの容量と整理」から消せます）。
- 生成の詳細設定の値は、生成のときに次回の既定として保存し、下書きと装備の記録に残ります。装備一覧の「再生成」では、サンプリング・背景除去・MOD のテクスチャと、画像ごとの背景除去の強制を
  記録の値に戻します（低 VRAM モードと通信の遮断は、今の設定のままです）。
- 見た目を作り直した装備を装備パッケージ（`.gdskin`）に書き出すと、元の装備の内部ID と元の 3D モデルの SHA-256 が記録に入ります。

設定画面には、ほかに次の項目があります（押したときだけ動きます）。

- **データの容量と整理**: データフォルダーの項目ごとの大きさと、整理で消せるものを表示します。「古いビルドを消す…」「古い導入の退避を消す…」
  「削除した装備を完全に消す…」「保存した入力画像を消す…」「失敗・中断・保存済みの下書きを消す…」は、消すものと残すもの（理由つき）を確認の画面に出し、
  チェックを入れてから消します。**消したものは元に戻せません。** 導入中のビルド、今の導入の前の状態（「受け取った MOD を外して元に戻す」の戻り先）のビルド、
  最新の成功したビルド、アンインストールと今の導入の前の状態に戻すときに使う退避、新しい退避 5 件、処理中・表示中の下書き、生成の画面の画像の欄で使っている入力画像は消しません。
  入力画像を消した装備を再生成するときは、画像を選び直します。自動では何も消しません（処理中のまま残った下書きも、起動時に「中断」の状態にするだけで、消しません）。
- **TRELLIS 実行環境の管理（照合し直す・入れ直す・削除）**: アプリのセットアップで作った取得先だけが対象です。
  「モデルを照合し直す…」は全部のファイルを SHA-256 で読み直し、合わないファイルだけを配布元から取り直します。
  「Python とパッケージを入れ直す…」は Python・PyTorch・パッケージを配布元から取り直して入れ替え、動作確認をします（取得は最大で約 4.2 GB）。
  「テキスト→3D のモデルを削除…」「TRELLIS 実行環境をすべて削除…」は、アプリが取得したものだけを消します（装備一覧・作った MOD・設定は消しません）。

> **入力する画像について**: 3D 生成に使う画像は、あなたが使う権利を持つものにしてください。他人の作品やキャラクターの画像から作った
> モデルを公開・配布すると、その権利者の権利を侵害するおそれがあります。

## Steam の起動オプション /basemods

このツールが作る MOD は「`/basemods`」方式です（メインキャンペーンで読み込まれます）。Steam の起動オプションに `/basemods` を設定してください。
このツールは起動オプションを自動では書き換えません（Steam の起動中に設定ファイルが上書きされるおそれがあるため）。

1. Steam のライブラリで Grim Dawn を右クリック →「プロパティ」
2. 「一般」→「起動オプション」に `/basemods` と入力（他のオプションがあれば、半角スペースで区切って後ろに追加）
3. Steam から Grim Dawn を起動する

- アプリの起動オプションの確認（設定画面の「環境チェック」・セットアップの「5. 起動オプション」・MOD の画面）は、今 Steam にログインしているユーザー（分からないときは最後にログインしたユーザー）の
  設定を読みます（読むだけです）。Steam の起動中に設定した直後は、Steam を終了するまで `/basemods` が無いと表示されることがあります。
  Steam を終了してから「再チェック」（MOD の画面では「更新」）を押してください。
- `mods\database.arz` は 1 つしか読まれないため、他のメインキャンペーン用 MOD とは同時に使えません。
- アンインストール後に他の `/basemods` の MOD を使わない場合は、起動オプションから `/basemods` を消してください。
- **セーブデータのバックアップ**: 初めて MOD を導入する前と、MOD を外す前に、セーブのフォルダー（`ドキュメント\My Games\Grim Dawn\save`。
  Steam クラウドを使っている場合は `Steam\userdata\<数字>\219990\remote\save` も）を、フォルダーごと別の場所にコピーしておくことをおすすめします。
  `/basemods` を付けずに起動したとき、Crucible・Custom Game でキャラクターを読み込んだときに、このツールの消耗品や収集済みのイリュージョンが
  どうなるかは確かめていません。

## マルチプレイについて（未確認）

**マルチプレイでの動作は確かめていません。** 次は見込みです。

- マルチプレイでは、参加する全員が同じ MOD（同じ `database.arz`）を導入している必要があると見込まれます。
  装備の組み合わせが違う MOD どうしでは、参加できない・表示が合わないおそれがあります。
- そのために、作った MOD をそのまま渡す共有ファイル（`.gdskinmod`）を用意しています。「MOD」→「3. マルチプレイ用の共有」で書き出し、
  受け取った人は「共有ファイルを読み込んで導入…」で、作り直さずに同じバイト列で導入できます。**受け取った側の MOD は置き換わります**
  （「受け取った MOD を外して元に戻す」で戻せます）。
- 画面に表示される**照合コード**（MOD 全体のコード。全ファイル（`database.arz`・見た目の `Items.arc`・表示名の `Text_XX.arc`）の名前と
  SHA-256 から作る 12 桁。例 `1A2B-3C4D-5E6F`）が全員同じなら、同じ MOD です。`database.arz` だけのコード（データベースのコード）は、
  最新のビルドの欄と確認の画面に別に出します。
- 照合コードが違うときは、「MOD」の画面の「照合の詳細」で、ファイルごとのコードと、どのファイルが違うか（データベースか、見た目・表示名だけか）を
  確かめられます。相手の照合コードを入力して「比べる」こともできます。受け取った MOD の確認の画面には、導入中の MOD・あなたの最新のビルドとの比較が出ます。
- 受け取った MOD の中身に、このツールが作る内容との違い（ゲームの版の違いか、作った人による書き換え）があると、確認の画面に項目ごとの注意を出します
  （これらの違いだけでは取り込みを止めません）。内容を確かめてから導入してください。
- 知らない人から受け取ったファイルは使わないでください（ハッシュは署名ではありません）。

確かめ方の手順は [docs/multiplayer_check.md](docs/multiplayer_check.md) にあります。結果を教えていただけると助かります。

| セットアップの取得が失敗する | 「再試行（続きから）」を押してください（取得済みのファイルは照合して再利用します。huggingface.co などへの接続が途中で切れて止まった場合も、再試行で続きから取得できます）。会社・学校のネットワークなどで github.com（転送先の codeload.github.com・release-assets.githubusercontent.com を含む）、huggingface.co（転送先の us.aws.cdn.hf.co などの配信用のサーバーを含む）、releases.astral.sh、download.pytorch.org、pypi.org、files.pythonhosted.org、dl.fbaipublicfiles.com、nvidia-kaolin.s3.us-east-2.amazonaws.com への接続が止められていると取得できません。「配布元がファイルを返しませんでした（HTTP 番号）」は、配布元のファイルが移動・削除されたか、プロキシ・フィルターで止められている可能性があります（何度も同じ場合は、アプリの新しい版を確かめてください）。「取得中のファイルに書き込めませんでした」は、ほかのアプリやウイルス対策ソフトが取得中のファイルを開いている可能性があるので、少し待ってから再試行してください。「空き容量が足りません」は取得先を空きの多いドライブに、「取得先のパスが長すぎます」は 80 文字以内の短いパスにしてください |
| 「Visual C++ 再頒布可能パッケージが必要です」（セットアップの動作確認） | [Microsoft の配布元](https://aka.ms/vc14/vc_redist.x64.exe)から Visual C++ 再頒布可能パッケージ（x64）の最新版を入れてから（管理者権限が要ります）、「再試行（続きから）」を押してください。取得済みのファイルは再利用します |
| 「GPU が見つかりません」（または「対応する GPU が見つかりません」）「GPU のドライバーが古いです」「GPU メモリが不足しています」 | NVIDIA のドライバーを R570 以降に更新してください。GPU メモリ 12 GB 未満、compute capability 6.0 未満の GPU では 3D 生成を使えません。他のアプリ（ゲームなど）を閉じてから生成してください。GPU メモリが 16 GB 未満のときやメモリ不足で失敗するときは、生成の詳細設定の「低 VRAM モード」を試してください |
| 「モデルを読み込めませんでした」／セットアップの動作確認が失敗する | 「詳細」とログを確かめてください。モデルのファイルが壊れている可能性があるときは、設定画面の「TRELLIS 実行環境の管理」の「モデルを照合し直す…」（全部のファイルを読み直し、合わないファイルだけを取り直す）を、Python・パッケージが壊れている可能性があるときは「Python とパッケージを入れ直す…」を使ってください（アプリのセットアップで作った取得先だけが対象です） |
| 照合し直しの結果に「セットアップの画面から取得し直してください」と出る | 合わないファイルがありましたが、ライセンス・注意事項への同意の記録が無いため取り直していません。左の「セットアップ」を実行すると、合わないファイルだけを取り直します |
| 設定画面の「TRELLIS 実行環境の管理」の操作（「Python とパッケージを入れ直す…」など）で失敗し、ヒントに「再試行（続きから）」と出る | このボタンはセットアップの画面のもので、設定画面にはありません（このアプリの制限です）。原因を直してから、設定画面で同じ操作のボタンをもう一度押してください |
| 「生成に使うファイルがありません」 | 生成の途中ではファイルを取得しないため、生成を止めています。左の「セットアップ」を実行してください（足りないファイルを取得し、取得済みのファイルは照合して再利用します）。ファイルが壊れている可能性があるときは「モデルを照合し直す…」を使ってください |
| 「基準メッシュがありません」 | エラーの画面の「基準メッシュを準備する」か、セットアップの「4. 基準メッシュ」で準備してください。Grim Dawn が見つからない場合は、設定画面でインストール先を指定してください |
| 「基準メッシュが壊れています」「基準メッシュを開けません」 | 壊れているときは、エラーの画面の「基準メッシュを準備する」か、設定画面の「ゲームから準備する」で取り出し直してください。開けないとき（ほかのアプリが使用中か、読み取りの権限がありません）は、ウイルス対策・バックアップ・同期（OneDrive など）のソフトを閉じるか一時停止するか、データフォルダーの `refs\` の読み取りの権限を確かめてから、もう一度試してください（「ゲームから準備する」では直りません。準備は開けないファイルを飛ばします） |
| 背景のある画像で人物の一部が消える／背景が残る | 「背景除去を確認」で確認し、うまくいかない場合は背景を透明にした PNG を使ってください。詳細設定の「背景除去」（アプリ側の背景除去と後処理）を「背景除去を確認」で見比べる方法もあります |
| 背景が 3D モデルに入る（板や台になる）／「ほぼ全体が不透明だったため、背景を除かずに生成しました」 | 角だけ透明なスクリーンショットなど、ほぼ全体が不透明な画像は背景が除かれません。画像の欄の「この画像の詳細設定」→「背景除去を強制する」をオンにして生成し直すか、背景を透明にした PNG にするか、JPEG で保存し直してください |
| 変換で「体から極端に離れた頂点があります」と出る／品質の注意「体から大きく離れた頂点…」が出る | GLB に、体から離れた壊れた部品・余計な部品（小さな破片や点など）があります。極端に離れている（体の高さの 100 倍より遠い）ときは変換できないので、GLB を作ったツールでその部品を取り除いてから書き出し直してください。それより近いときは変換を続け、大きさと位置の合わせ込みからだけ除きます（その部品は装備に残ります）。プレビューで確かめ、不要なら同じように取り除いてください |
| ゲーム内で足元やすねが崩れる・裂ける | 以前の版のアプリで変換した装備は、装備一覧で「変換し直す」を押してから、「MOD を作成し直す」→「Grim Dawn に導入」を行ってください。それでも崩れる場合は「再生成」で別のシードを試すか、腕と脚を少し開いた立ち姿の画像を使ってください |
| 「MOD の作成が途中で止まりました」 | mods フォルダーは変更していません。エラーの画面の「詳細」に、ゲーム付属のツールの出力などの原因があります |
| 「ゲームの付属ツールがありません」／設定画面の「環境チェック」で ArchiveTool.exe・TextureCompiler.exe が「ありません」 | Steam のライブラリで Grim Dawn のプロパティ →「インストール済みファイル」→「ゲームファイルの整合性を確認」で戻せます |
| 導入・アンインストールに失敗した | 書き込みに失敗したときは、mods フォルダーを操作の前の状態に戻します。「元に戻せなかったファイルがあります」と出たときは、Grim Dawn とファイルを開いているプログラムを閉じてから、もう一度同じ操作を行ってください（操作の前のファイルは、データフォルダーの `install\backups\<ID>` に退避してあります）。mods フォルダーに読み取り専用のファイルがあると、変更の前の確認の段階で止めて知らせます（エクスプローラーのプロパティで「読み取り専用」を外してください）。「導入の記録を保存できませんでした」と出たときは、mods フォルダーは変更されていますが、導入の記録（データフォルダーの `install\`）が古いままです。途中でバックエンドに接続できなくなったときと同じく、「MOD」の画面の「mods フォルダーの状態」の表で今の状態を確かめてください。完了の表示に「注意があります」と出たときは、注意の文を確かめてください（「装備ライブラリの導入状態を更新できませんでした」は、mods フォルダーの変更は終わっていて、装備一覧の「導入済み」などの表示が古いことがあるという意味です。理由はログにあります） |
| 3D プレビューに「この PC では 3D プレビューを表示できません（WebGL を使えません…）」と出る | グラフィックスのドライバーを更新すると表示できることがあります。変換の結果は、プレビューの「変換の確認画像」のタブでも確かめられます |
| ゲームの更新（パッチ）の後／「MOD」の画面に警告のバナーが出る | MOD は補給官の品ぞろえ（公式のレコード）の写しを含むため、ゲームの更新で品ぞろえが変わると、古い内容で上書きしてしまいます。バナーに変わったティアが出たら、「MOD を作り直す」（「MOD を作成」）で作り直してから、「最新のビルドを導入する」（「Grim Dawn に導入」）で導入し直してください。最新のビルドが既に今のゲームに合っているときは、導入し直すだけで済みます。「ゲームの版」の行には、Steam のビルド番号（MOD を作ったときと今）と、次のどれかの状態（同じ版／更新されたが品ぞろえは変わっていないので、このまま使える／今のゲームに合った MOD が必要／記録が無いので比べていない）を表示します |
| 受け取った MOD を使っているときにゲームが更新され、警告のバナーが出る | MOD を作った人に、今のゲームで作り直して共有し直してもらい、受け取り直して導入してください。自分の MOD に置き換えると、相手と照合コードが合わなくなります |
| アンインストールしても AI Skin の古い MOD が残る | アンインストールは「最初の導入の前の状態」に戻します。その時点で mods フォルダーにこのアプリの記録の無い AI Skin の MOD（試作など）があった場合は、それに戻り、ゲームで読み込まれます（MOD の画面と確認の画面に表示します）。不要なら、ゲームを終了してから「mods フォルダーを開く」で、該当のファイルを別の場所へ移してください |
| 相手と照合コードが合わない | 「MOD」の画面の「照合の詳細」で、どのファイルが違うかを確かめてください。`database.arz` が同じで見た目（`Items.arc`）・表示名（`Text_XX.arc`）だけが違う場合は、接続できる見込みですが、互いの画面で装備の見た目や名前が違って見えます |
| ゲームでイリュージョンが表示されない・補給官の在庫に無い | Steam の起動オプションに `/basemods` があるか、「MOD」のページで導入済みかを確かめてください。他の `/basemods` の MOD と同時には使えません（MOD の画面の表の「他のファイル（読み込まれます）」も確かめてください）。補給官の在庫は Survivors の評判が Friendly 以上で表示されます。イリュージョンは装備中の部位にしか適用できないので、頭・胴・肩・手・脚・足に何かを装備しているかも確かめてください（[使い方](#使い方)の 5） |
| 英語以外の設定のゲームで、装備名・説明が正しく出ない | MOD には 13 言語の表示名のファイル（`Text_XX.arc`）を入れています（日本語は日本語名、ほかの言語は英語名）。日本語の設定のゲームで日本語名・日本語の説明が出ることは確かめました（2026-11-18）。英語と日本語以外の設定のゲームで読まれるかは、まだゲーム内で確かめていません。結果を教えていただけると助かります |
| 英語の画面で、一部の文が日本語のまま | 表示言語を変えた後は、アプリを起動し直すと反映されます（それまでは前の言語のままです）。切り替える前に書かれたログの行は、書いたときの言語のままです。利用者が入力した文（装備名など）は、入力したとおりに表示します。エラーの「詳細」に入る Windows のエラーの文は、Windows の表示言語のままです。開発者向けの道具（コマンドラインの gdconvert・modbuilder、配布物の作成と公開の検査のスクリプト）と、docs/ の文書（マルチプレイの確認手順）は日本語だけです。これら以外で日本語が出るところがあれば、教えていただけると助かります（[CONTRIBUTING.md](CONTRIBUTING.md)） |
| 他のアプリの中から起動したときに、作った装備が普段のアプリで見えない | 一部のアプリ（MSIX のパッケージのアプリ）の中から起動すると、データフォルダーが別の場所（仮想フォルダー）に分かれることがあります。エクスプローラーなどから普通に起動し、装備一覧の「取り込む…」で取り込んでください |

ログ（`%LOCALAPPDATA%\GrimDawnSkinMOD\logs\` の `app-日付.log`・`backend-日付.log`）には、入力した画像や文章の中身は残しません。
不具合を報告するときは、ログの中にあなたのフォルダー名などが無いかを確かめてから添えてください。

## アンインストール

1. **ゲームに導入した MOD を外す**: アプリの「MOD」のページで「アンインストール」を押します（最初の導入の前の状態に戻ります）。
   Steam の起動オプションの `/basemods` も必要に応じて消してください。
   最初の導入の前に、このアプリの記録の無い AI Skin の古い MOD（試作など）があった場合は、それに戻ります（画面に表示します。
   [トラブルシューティング](#トラブルシューティング)）。
2. **3D 生成の実行環境を消す（任意）**: アプリを消す前に、設定画面の「TRELLIS 実行環境の管理」の「TRELLIS 実行環境をすべて削除…」で、
   アプリが取得した実行環境とモデル（約 13 GB。テキスト→3D の項目も取得したときは約 19 GB）を消せます（アプリのセットアップで作った取得先だけが対象です。利用者が置いたほかのファイルは残します）。
3. **アプリを消す**: 展開したフォルダーごと削除します（レジストリやスタートメニューには何も登録していません）。
4. **データを消す（任意）**: **先に 1 のアンインストールを行ってください。** 導入のときに他の MOD のファイルを置き換えた場合、
   その元のファイルはデータフォルダーの `install\backups` にしか無く、データフォルダーを消すと戻せなくなります。
   そのうえで `%LOCALAPPDATA%\GrimDawnSkinMOD` を削除します。作った装備・MOD のビルド・導入の記録と退避・設定・ログ・
   3D 生成の実行環境とモデル（既定の場所の場合）が消えます。実行環境の取得先が別の場所の場合（セットアップで選んだ場所や、
   利用者のフォルダー名に全角文字があるなどで既定になる `%SystemDrive%\GDSkinStudio\trellis-runtime`）は、2 を行うか、そのフォルダーも削除してください。

アプリを新しい版に入れ替えるときは、3 だけを行い、新しい ZIP を展開してください。データフォルダーは残るので、作った装備・取得したモデルはそのまま使えます。

### アプリから外せないとき（導入の記録が無いとき）

データフォルダーを消した、別の場所のデータフォルダーで導入した（[トラブルシューティング](#トラブルシューティング)の仮想フォルダーの件など）といった場合、
アプリの「アンインストール」は押せず（押せたときも「このアプリで導入した MOD はありません」で止まります）、mods フォルダーのファイルは残ります。

1. 他に `/basemods` の MOD を使わないなら、Steam の起動オプションから `/basemods` を消します（これだけで、mods フォルダーの直下のファイルは読まれなくなります）。
2. ファイルも消す場合は、Grim Dawn を終了し、アプリの「MOD」の画面で mods フォルダーのファイルの判定を見ます。
   「このアプリが導入」または「記録の無い AI Skin の MOD」と表示された、mods フォルダーの直下の `database.arz`・`Items.arc`・`Text_XX.arc`
   （13 言語の `Text_CS.arc`〜`Text_ZH.arc`。以前の版で作った MOD は `Text_EN.arc`（と `Text_JA.arc`）だけ）だけを消します。
   「他の MOD・不明なファイル」と表示されたファイルは消さないでください。`mods\survivalmode`（Crucible の DLC）などのフォルダーも消さないでください。

ゲームのセーブデータは、MOD を外す前にバックアップしておくことをおすすめします（[Steam の起動オプション /basemods](#steam-の起動オプション-basemods)）。

## 開発者向け

このリポジトリには、アプリを動かす・配布用 ZIP を作るのに必要なものだけを入れています。

| フォルダー | 内容 |
|---|---|
| `app/frontend/` | アプリの画面（C# / .NET 10 の WPF。3D プレビューは WebView2 と同梱の three.js） |
| `app/backend/` | アプリのバックエンド（Python。生成・変換・MOD の作成をジョブとして動かす） |
| `src/` | 部品: `gdmesh`（`.msh` の読み書き）・`gdconvert`（GLB → 男性用・女性用の `.msh` と `.tex`）・`modbuilder`（MOD の作成・検証・導入） |
| `scripts/trellis/` | 3D 生成（TRELLIS）のスクリプトと、初回のセットアップで取得するものの定義（版・ハッシュ） |
| `scripts/package/`・`scripts/publish/` | 配布用 ZIP の作成と検査、公開の前の検査（個人情報・ゲームのファイルなどが入っていないか） |
| `scripts/gdconvert.py`・`scripts/modbuilder.py` | 部品のコマンドラインの入口（`--help` で使い方） |
| `licenses/` | 第三者のライセンスの全文（初回のセットアップで取得するもの・配布用 ZIP に同梱する .NET の部品） |
| `docs/multiplayer_check.md` | マルチプレイでの見た目の確認手順 |

開発中に使ったテスト・画面の自動操作の道具・試作・調査と設計の記録は入れていません。コードの注釈にある `docs/` の文書や、
D-001・B-001・点検 C14 などの番号は、このリポジトリに含めていない開発の記録を指します。
`scripts/trellis/setup_trellis_env.ps1` の `-Mode dev`（開発用の比較の部品）に使うファイルも入れていません（`-Mode runtime` に使うファイルは入っています）。

### 必要なもの

| もの | 用途 |
|---|---|
| Windows 10 / 11（64 bit） | 全体 |
| .NET 10 SDK | 画面（WPF）のビルド |
| Python 3.11（`py` ランチャー）と `numpy`・`scipy`・`Pillow`・`lz4`・`fast-simplification`・`xatlas` | バックエンド・変換・MOD の作成（配布用 ZIP に入れる版とハッシュは `scripts/package/backend-requirements.txt`） |

```bash
py -3.11 -m pip install numpy scipy Pillow lz4 fast-simplification xatlas
```

### ソースから動かす

```bash
dotnet build app/frontend/GDSkinStudio.sln -c Debug
```

```bash
app/frontend/GDSkinStudio/bin/Debug/net10.0-windows/GDSkinStudio.exe
```

- バックエンドを動かす Python は、設定画面の「バックエンドの Python」で指定したもの → `%LOCALAPPDATA%\Programs\Python\Python311\python.exe` → `py -3.11` の順に探します。
- データフォルダーの既定は、配布用 ZIP のアプリと同じ `%LOCALAPPDATA%\GrimDawnSkinMOD` です。試すときは `--data-dir <フォルダー>` で別の場所にしてください。
- 3D 生成の実行環境は、アプリの「セットアップ」で取得します。

### 配布用 ZIP を作る

```bash
py -3.11 scripts/package/build_package.py
```

- `build/package/GDSkinStudio-<版>-win-x64.zip` と、展開した後と同じ中身のフォルダーができます。
- .NET のパッケージ（NuGet）、Python の embeddable 版（python.org。大きさ・SHA-256・MD5 を照合）、Python のパッケージ（PyPI。ハッシュを照合）を取得します。
- コピーする範囲に git で追跡していないファイルがあると止まります。作成の最後に `scripts/package/check_package.py` の検査を行います。

変更の送り方は [CONTRIBUTING.md](CONTRIBUTING.md)、変更履歴は [CHANGELOG.md](CHANGELOG.md) にあります。
